# Provider

Professional profile, self-declared categories, private onboarding documents, Identity-backed administrator verification, quote eligibility and customer reviews for completed jobs. See [workflow and manual deployment](../../../docs/technician-order-workflow.md).

No administrator category approval is required. Credentials/identity documents still require review. Rating is calculated from verified-job reviews; completed-job counts come from ServiceRequest. The business-plan reference is in docs/references/Zumaris-BP.pdf. No direct cross-service database access.
