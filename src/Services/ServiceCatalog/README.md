# ServiceCatalog

Owns service categories, service definitions and property-area options. Authenticated read-only lists are implemented at `GET /api/areas` and `GET /api/categories`; public icon routes support browser image display.

- [Area setup and IIS deployment](../../../docs/service-catalog-areas.md)
- [Category setup, SQL and icon deployment](../../../docs/service-catalog-categories.md)

Service definitions and order integration remain unimplemented.
